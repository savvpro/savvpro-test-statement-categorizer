# Ledgerly sample statements

Fictional data only (persona Dana Reyes; fictional tenants, lenders and vendors). Generated by `scripts/generate_samples.py`. Each `<file>.expected.json` holds the labels for that file. Row index: CSV = data line after the header (malformed and footer lines count, blank lines do not); OFX = STMTTRN order.

- `checking_q1_2026.csv`: Jan-Mar business checking, signed amounts; tenant Zelle rent, deposits, mortgage, bills, transfers and Zelle edge cases (D01-D09, D15-D22, D24-D29, D31, D32, D37-D39).
- `card_q1_2026.csv`: credit card with separate Debit/Credit columns; merchant mixed-use, refunds, capital-improvement and direction-conflict cases (D10-D14, D23, D30, D33-D36, P08).
- `checking_messy_bom_crlf.csv`: UTF-8 BOM, CRLF, 3 preamble lines, `;` delimiter, decimal comma, ambiguous MM/DD dates, blank line, 2 malformed rows, zero amount, `(45,00)` negative, Ending Balance footer (P01, P03, P06, P07, P09, P10, P22, P24). P04, P05 and P15 are line-level and produce no transaction row.
- `checking_q1_2026.ofx`: OFX 1.x SGML with no closing tags on leaf elements; duplicate FITID and a MEMO-only row (P17, P19, P20).
- `card_q1_2026_v2.ofx`: OFX 2.x XML credit card statement (P18).
- `checking_overlap_feb_apr.csv`: Feb-Mar rows copied verbatim from the Q1 checking file plus April rows; overlapping rows are cross-upload duplicates (D41).
