# AI Usage Report

## 1. AI Tools Used

ChatGPT was used as an assistance tool during development of the Statement Categorizer project.

## 2. How AI Assisted

AI assistance was used to help with:

- Understanding the assessment requirements and breaking the work into manageable steps.
- Developing and troubleshooting the frontend-to-backend API integration.
- Reviewing Python code structure and explaining the transaction categorization logic.
- Preparing project documentation and setup instructions.
- Identifying areas that needed testing and verification.

## 3. Human Review and Validation

The implementation was reviewed and tested during development. Backend tests and the frontend production build were run during development.

The final submitted version must be tested again before submission. Any test results reported in the final submission should reflect the actual results from that version.

## 4. Issues Encountered

During development, the frontend upload and transaction-editing integration required troubleshooting to align API requests with the backend endpoints.

The implementation also has limitations, including keyword-based merchant matching, a simple negative-amount refund rule, and PDF parsing that depends on table structure.

## 5. AI Limitations

AI-generated suggestions can contain errors or assumptions that do not match the existing code. Suggestions were therefore checked against the project implementation and tested where possible.

The categorization logic is implemented using Python rules and does not rely on a large AI model to classify transactions.
