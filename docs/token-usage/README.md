# Token usage proof

Evidence for the token section of `AI_USAGE.md`.

- `claude-code-usage-SS.png`: Claude Code "Account & Usage" panel taken in the final session (percent of plan limit).
- `claude-code-usage-SS-other-session.png`: the same panel taken in another Claude Code window.
- `claude-chat-usage-SS.png`: claude.ai Settings, Usage page, for the chat.
- `claude-code-session-logs.txt`: token counts for the five Claude Code sessions of this project, summed from the local session logs in `~/.claude/projects/`. They are what the logs record, not a billing statement.
- `current-session.txt`: the same figures for the final session only, as a snapshot taken before that session ended (so it is lower than the final figure).

The screenshots show percent of the plan limit, which is shared across chat and Claude Code, not token counts. The token numbers in `AI_USAGE.md` come from the session logs.
